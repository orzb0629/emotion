# 특수문자 입력기

광고와 로그인 없이 엄선한 121개의 텍스트 이모티콘과 특수문자를 클릭해서 복사하는 React + Vite 웹앱입니다. 서버·DB·추적 도구를 사용하지 않습니다.

## 처음 실행하기

1. Node.js 22.12 이상(LTS 권장)을 설치합니다. 설치 후 VS Code를 다시 켭니다.
2. VS Code에서 `C:\vscode\emotion` 폴더를 엽니다.
3. 메뉴의 **터미널 → 새 터미널**을 선택합니다.
4. 아래 명령어를 차례대로 실행합니다.

```powershell
cd C:\vscode\emotion
npm install
npm run dev
```

PowerShell에서 `npm.ps1` 실행 정책 오류가 나면 시스템 설정을 바꾸지 않고 아래 명령어를 사용하세요.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널의 Local 주소(기본 `http://127.0.0.1:5173/`)를 브라우저로 엽니다. 포트가 사용 중이면 Vite가 다른 포트를 표시합니다. 서버 종료는 터미널에서 `Ctrl+C`입니다. `.npmrc`는 npm 캐시를 이 프로젝트의 `.npm-cache`에 저장하도록 설정합니다.

## 사용하기

- 카드의 문자 영역을 한 번 클릭하면 복사됩니다. 메신저에 `Ctrl+V`(Mac은 `⌘V`)로 붙여 넣으세요.
- ☆는 즐겨찾기를 추가하거나 해제합니다. 첫 화면과 즐겨찾기 메뉴에서 바로 찾을 수 있습니다.
- 카테고리, 세부 카테고리, 검색어로 문자를 찾습니다. 검색은 선택한 카테고리 안에서 문자와 분류 이름을 대상으로 작동합니다.
- 최근 사용은 마지막으로 복사한 서로 다른 문자 20개를 저장합니다.
- **내 문자 추가**에서 한 줄의 이모티콘이나 특수문자를 추가하세요. 일반 문장·일반 글자·중복 문자는 등록할 수 없습니다. 내 문자에서 삭제할 수 있습니다.
- 복사 권한이 없으면 수동 복사 창의 문자를 선택해서 복사하세요. 실제 복사 후 **복사했어요**를 누르면 최근 사용에 기록됩니다.
- 즐겨찾기, 최근 사용, 직접 추가한 문자는 이 브라우저의 localStorage에 저장됩니다. 브라우저 데이터를 지우면 사라지며 기기 사이에 동기화되지 않습니다. 시크릿 창에서는 창을 닫을 때 사라질 수 있습니다.
- 메신저와 운영체제의 글꼴에 따라 문자 모양이 달라질 수 있습니다.

## 문자 목록 수정

`src/characters.js`의 `groups`를 수정하세요. 각 그룹은 `[큰 카테고리, 세부 카테고리, 문자 배열]`입니다. 복사 시에는 `text`만 사용하며 설명이나 카테고리 이름은 포함하지 않습니다. 기존 항목의 순서를 바꾸면 저장된 즐겨찾기의 연결이 바뀔 수 있으므로, 기존 항목은 유지하고 뒤에 추가하는 것을 권장합니다.

기본 목록은 직접 엄선했습니다. 참고 사이트의 코드·디자인·전체 목록을 복제하거나 목록을 수집하지 않았습니다. 한글 음절처럼 보이는 일부 기호는 얼굴의 눈 등으로 사용됩니다.

## 검증 및 배포

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

테스트는 DOM 환경에서 복사 API 모의 호출, 검색·세부 분류, 즐겨찾기와 사용자 문자 저장·삭제, 최근 20개 제한, 수동 복사 안내, 데이터 무결성을 확인합니다. 실제 브라우저 권한과 메신저 붙여 넣기는 별도 수동 확인이 필요합니다.

추후 Vercel에 이 프로젝트를 연결할 때 프레임워크 **Vite**, 빌드 명령 **npm run build**, 출력 디렉터리 **dist**를 지정하세요. 환경 변수는 필요 없습니다. 현재는 외부에 배포하지 않았습니다.
